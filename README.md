Cartographic Trips
This project presents ready-to-use maps created for outdoor trips and tourism.
The Python code used to generate the maps may be released later as part of the documentation or as a separate project.
The project aims to demonstrate how, with minimal effort, a small set of dependencies, and a clean file structure, it is possible to create a clear, functional, and visually pleasant map — suitable for both desktop and mobile devices.
